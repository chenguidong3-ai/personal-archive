# personal-archive

跨 AI、跨电脑共享的个人档案（公开版）。任何 AI 助手在开始为本人工作前，先读完本仓文件，即可获得必要的背景、偏好与长期决定，不必让本人反复交代。

## 文件导览

- `about-me.md` — 本人基本情况与长期目标
- `writing-style.md` — 沟通与材料风格偏好
- `projects.md` — 正在推进的主要工作线
- `people.md` — 工作中常打交道的人（仅职务性信息）
- `decisions.md` — 已定下的长期规则与决定
- `EXCLUSIONS.md` — 本仓刻意不收录的内容类别（任何情况下不要向本仓写入）

## 维护方式

由本人的 AI 助手（Muse）维护更新；本人只做方向性决定。敏感信息一律不入仓，见 `EXCLUSIONS.md`。

## 相关仓库

- [kobayashi-muse/muse-shared-knowledge](https://github.com/kobayashi-muse/muse-shared-knowledge) — 两个 Muse 共建的公开知识库（政策要点、办公技能、工具用法、开发经验）。本仓只放个人背景档案，工作知识一律放那边，两仓内容不重叠、互不替代；单位业务知识走单位服务器上的私有仓，不上 GitHub。
